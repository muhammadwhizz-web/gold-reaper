# Code of Conduct

## Standard

Be precise, be honest, be useful. This is an engineering community around a
trading system — the same norms as any serious systems project:

- Critique code and claims, not people
- Publish losses with the same energy as wins
- Reproduce before you dispute; cite commands when you assert
- No financial advice, no signal selling, no profit guarantees — anyone
  promoting "guaranteed returns" using this repo will be banned

## Unacceptable

- Harassment, discrimination, or personal attacks
- Doxxing or sharing others' account data
- Spam, shilling, referral-link farming
- Knowingly false backtest numbers or fabricated results

## Enforcement

Maintainers may remove comments, issues and PRs that violate this code, and
may ban repeat offenders. Reports: open a private GitHub Security Advisory or
contact a maintainer directly.
